
## Run locally

Open `index.html` in a browser. No build step or dependencies are needed.

## Deploy with GitHub Pages

1. Go to **Settings**, then **Pages**.
2. Set the branch to `main` and the folder to `/ (root)`, then save.
3. The site goes live at `https://<username>.github.io/<repo-name>/`.

## Notes

- Keep `index.html` and `port.css` in the same folder.
- The certificate buttons expect these files inside `certificates/`: `c-essentials.pdf`, `java-foundations.pdf` and `mongodb-certificate.pdf`.
- The navigation links are hidden on screens narrower than 750px.
